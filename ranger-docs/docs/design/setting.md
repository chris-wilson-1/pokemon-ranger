# Setting

**Status: open.** Deliberately undecided while we focus on tech demo work.

## What we know

- A region with a Ranger Corps as an established institution
- Enough wilderness/biome variety to support a "field operative" fantasy
- Capable of supporting both wholesome early-game locations (training base, friendly towns) and the darker material the [story arc](../vision/tone-and-arc.md) demands later

## What we don't know yet

- Whether to reuse Hoenn geography as a starting point or build a custom region from scratch
- Whether the region has a recent historical wound (post-war, post-disaster, post-incident) or is ostensibly peaceful
- How many ranger bases / "gym equivalents" the region supports
- Whether the region is contained or borders something hostile/unknown

## When we'll decide

After the tech demo proves the build → edit → test loop is comfortable. Setting decisions are downstream of:

1. Knowing how much map work we can realistically scope
2. Knowing whether we're confident enough with tilesets to build custom areas vs. reskinning Hoenn
3. The story turn being defined enough to know what the *world* needs to support
