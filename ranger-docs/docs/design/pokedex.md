# Pokédex Curation

All gens available via `pokeemerald-expansion`. We curate aggressively — target ~300 species.

## Curation principles

1. **Ecological fit** — favour Pokémon with strong habitat/wildlife associations. Ranger fantasy lives or dies on this.
2. **Generation spread** — pull from every gen. Players should encounter unexpected favourites.
3. **Mega Evolution roster** — Megas are on. Choose Megas that feel iconic to the ranger fantasy (Arcanine line, Lucario, etc.).
4. **No filler** — every species in the dex must have a reason to be there.
5. **Lock the dex early** — retroactive removal breaks encounter tables everywhere.

## Out of scope for v1

- Custom Megas (e.g. Mega Flygon) — each one is a small project of its own (sprites, stats, ability tables, stone item)
- Regional variants beyond what's already in expansion
- Custom species
