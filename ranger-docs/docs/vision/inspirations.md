# Inspirations

## Primary: Pokémon Unbound

Unbound is the lodestar. What we're taking:

- **Narrative ambition** — high-stakes, morally complex plot that doesn't talk down to the player
- **Escalation** — the early game sets one expectation, the late game subverts it
- **Mechanical polish** — tight battles, fair-but-hard AI, intentional team building
- **Difficulty as a design value** — fights matter, the game expects you to engage
- **QoL respect** — modern conveniences (perfect IVs, easy EV/nature/ability tuning) so the player's effort goes into *playing*, not into *prep*

What we're explicitly **not** copying from Unbound:

- Cinematic cutscenes, camera pans, mugshot dialogue portraits
- Difficulty mode select (we ship one curve)
- Massive side content density (bounties, mining, frontier facilities)
- Custom UI overhaul
- Multi-region scope

## Secondary: Pokémon Ranger (the original DS games)

Aesthetic and thematic source only. We're stealing:

- The Ranger Corps as an institution — bases, ranks, mission deployments
- The "Pokémon are in danger and you protect them" emotional hook
- Field-operative fantasy rather than champion-seeker fantasy
- Partner Pokémon framing

We're **not** trying to simulate stylus capture, temporary captures, or any of the Ranger-specific mechanics. See [Pillars #3](pillars.md).

## Reference points (lighter touch)

- **Radical Red** — text speed, frictionless prep, AI that respects the player
- **Pokémon Dreamstone** — earlier inspiration, since dropped as primary reference but still informs the "curated, intentional" approach
