# Glossary

Project-specific shorthand. Upstream pokeemerald terms aren't redefined here — see the upstream docs for those.

| Term | Meaning |
|---|---|
| **Ranger Base** | A "gym town" — Ranger Corps facility where missions are briefed, debriefed, and rank-ups happen. |
| **Ops Board** | The NPC/object at a Ranger Base that hands out mission briefings. |
| **Mission** | A "gym arc" — briefing → field deployment → debrief → (sometimes) rank-up. |
| **Rank-up** | Promotion event. Replaces badge ceremonies. Gets custom presentation. |
| **The turn** | The story moment where the wholesome opening tone flips to something darker. See [Tone & Story Arc](../vision/tone-and-arc.md). |
| **Partner Ranger** | An NPC follower assigned to specific missions. See [Partner NPCs](../design/partner-npcs.md). |
| **Ranger Gear** | Reskinned HMs and key items. See [Ranger Gear](../design/ranger-gear.md). |
| **Frictionless prep** | Design principle: team building (IVs, EVs, natures, abilities) is cheap and fast — challenge lives in fights, not in grinding. |
| **The expansion** | Shorthand for `pokeemerald-expansion` — the base we're built on. |
| **Pinned** | Locked to `pokeemerald-expansion` 1.15.1; we don't pull upstream `master` wholesale. |
